# 왜관 낙동강 충적층 지하수 가뭄 시나리오 웹앱

MODFLOW 6를 계산 엔진으로 쓰는 Streamlit 웹앱입니다. 강수량을 줄였을 때(가뭄) 경북 칠곡군 왜관읍 낙동강 충적층의 지하수위가 어떻게 변하는지 모의하고 대시보드로 비교합니다.

## 기능
1. **모의조건 설정**: 강수 배율(30~150%), 수리전도도·비산출률·함양률·영농기 양수량·칠곡보 수위
2. **모델 실행**: 버튼을 누르면 flopy가 MODFLOW 6 입력을 만들고 실제로 실행 (약 1초)
3. **결과 시각화**: KPI(평균·최저 수위, 낙동강 유출량), 강수·수위 시계열, 수두 공간분포, 단면
4. **시나리오 비교**: 실행한 시나리오를 누적 비교, 강수 배율 50~120% 민감도 일괄 실행
5. **검증**: 관측 수위 재현(2021~2024 월평균 48개월) + Theis 해석해 비교

## 모델 개요
| 항목 | 내용 |
| --- | --- |
| 엔진 | MODFLOW 6 (flopy) |
| 대상 | 국가지하수관측망 칠곡왜관(충적, 82045) |
| 기간 | 2021-01 ~ 2025-12, 월 단위 (2025년은 관측 미공개로 예측 구간) |
| 격자 | 1층 자유면, 10 × 60 셀 (3 km × 1 km) |
| 경계 | 낙동강 RIV(칠곡보 관리수위 EL. 25.5 m), 배수로 DRN, 함양 RCH, 증발산 EVT, 영농기 양수 WEL |

## 검증 결과
- 관측 재현: RMSE 0.13 m, r 0.85, NSE 0.71 (2021~2024 월평균)
- Theis 해석해: 평균 상대오차 0.7 %

## 자료 출처
- 지하수위·관측정 제원: 국가지하수정보센터(GIMS), 한국수자원공사
- 강수·기온: 기상청 날씨누리 과거관측(구미, 279)
- 수리상수 문헌값: 낙동강 중·하류 하성충적층 지하수-지표수 연관성 평가

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
MODFLOW 6 실행 파일은 첫 실행 때 공식 릴리스(MODFLOW-ORG/executables)에서 자동으로 내려받습니다.

## 파일
- `app.py` 웹앱 · `model.py` MODFLOW 6 모델 · `verify_theis.py` Theis 검증
- `calibrate.py` 보정 · `calibrated.json` 보정값 · `data/` 관측 자료
